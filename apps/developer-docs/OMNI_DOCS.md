Omni-protocol developer docs (Next.js shell)

Baseline **Next.js 16 / React 19 + Tailwind 4**. Extend with **FumaDocs** packages (`fumadocs-ui`, `fumadocs-mdx`) following upstream guides when ready.

Included routes:

- `/` landing (default template)
- `/api/health` — JSON `{ "status": "ok" }` for smoke tests + OpenAPI alignment

Development:

```bash
npm run dev
```

_From repo root: `npm run apps:docs`._
