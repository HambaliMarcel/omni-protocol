# OpenSpec workspace

Product and engineering specs live here (intent before code).

Templates:

| File | Purpose |
|------|---------|
| `templates/feature-spec.md` | User story, acceptance, non-goals |
| `templates/rfc-light.md` | Short design rationale |
| `templates/implementation-plan.md` | Phased rollout + verification |

Workflow:

1. Copy template → `YYYY-MM-topic.md`
2. Link related ADRs in `/adr`
3. PR references spec paths in description
