# Omni-Protocol hub (portable stub)

When you run **`npm run omni:bootstrap`**, this folder copies into **`%USERPROFILE%\.cursor\omni-protocol`** (Windows) or **`~/.cursor/omni-protocol`** on Unix.

Treat it as a **pointer hub**: the authoritative portable docs live in **this repo** under **`docs/cursor-global/`**. If you had a richer personal hub on another PC, merge any extra Markdown you still want.
